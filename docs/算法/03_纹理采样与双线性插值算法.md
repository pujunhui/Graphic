# 纹理采样与双线性插值滤波算法

纹理贴图用于为多边形表面赋予丰富的色彩与高频细节。当摄像机靠近或远离表面时，屏幕像素（Pixel）与纹理像素（Texel）的覆盖比例不再是 $1:1$。如果采样算法选择不当，会产生严重的马赛克锯齿或摩尔纹。本模块解析最近邻采样与双线性插值滤波的数学原理与工程实现。

---

## 1. 纹理映射基础与连续坐标转换

- 纹理空间采用归一化 UV 坐标 $(u, v) \in [0.0, 1.0]^2$。
- 给定宽为 $W$、高为 $H$ 的二维纹理位图，连续 UV 坐标对应的连续纹素坐标 $(x, y)$ 为：
  $$x = u \cdot (W - 1), \quad y = v \cdot (H - 1)$$
  这里乘以 $W - 1$ 是因为第 0 个纹素中心在 0，第 $W-1$ 个纹素中心在 $W-1$。

---

## 2. 最近邻采样（Nearest Neighbor Filtering）

### 2.1 算法原理
直接将浮点纹素坐标 $(x, y)$ 四舍五入到最近的整数纹素网格点：
$$x_{\text{int}} = \text{round}(x), \quad y_{\text{int}} = \text{round}(y)$$
从纹理内存数组中提取像素色：
$$\text{Color} = \text{Buffer}[y_{\text{int}} \times W + x_{\text{int}}]$$

### 2.2 特点与缺陷
- **优点**：仅需一次浮点四舍五入与一次内存读取，计算开销极小。
- **缺点**：当纹理被放大（Magnification，即一个纹素跨越多个屏幕像素）时，相邻屏幕像素采样到同一个离散纹素，呈现出极其明显的**方块马赛克（Pixelation 锯齿）**。

---

## 3. 双线性插值滤波（Bilinear Filtering）

为了在纹理放大时获得平滑过渡的视觉效果，双线性插值考虑采样点周围最近的 **4 个相邻纹素**，根据采样点到这 4 个纹素中心的相对距离加权平均。

```
(left, top)        Q12 ─────── R2 ─────── Q22  (right, top)
                        │       │       │
                        │       │ (x,y) │
                        │       P       │
                        │       │       │
(left, bottom)     Q11 ─────── R1 ─────── Q21  (right, bottom)
```

### 3.1 寻找四邻域纹素网格
对于浮点坐标 $(x, y)$：
- 确定左、右、下、上边界整数索引：
  $$\text{left} = \lfloor x \rfloor, \quad \text{right} = \lceil x \rceil$$
  $$\text{bottom} = \lfloor y \rfloor, \quad \text{top} = \lceil y \rceil$$
- 提取 4 个角点的颜色：
  - 左下：$Q_{11} = \text{Buffer}[\text{bottom} \times W + \text{left}]$
  - 右下：$Q_{21} = \text{Buffer}[\text{bottom} \times W + \text{right}]$
  - 左上：$Q_{12} = \text{Buffer}[\text{top} \times W + \text{left}]$
  - 右上：$Q_{22} = \text{Buffer}[\text{top} \times W + \text{right}]$

### 3.2 插值权重与除零边界保护
计算采样点在网格单元内的水平偏移比率 $x_{\text{scale}}$ 与垂直偏移比率 $y_{\text{scale}}$：
$$x_{\text{scale}} = \begin{cases} 1.0, & \text{right} == \text{left} \\ \dfrac{x - \text{left}}{\text{right} - \text{left}}, & \text{otherwise} \end{cases}$$
$$y_{\text{scale}} = \begin{cases} 1.0, & \text{top} == \text{bottom} \\ \dfrac{y - \text{bottom}}{\text{top} - \text{bottom}}, & \text{otherwise} \end{cases}$$
> **工程考量**：当采样点恰好落在整数网格线上时，$\text{top} == \text{bottom}$，若直接做除法会导致浮点除以 0 产生 NaN。显式判断分支避免了崩溃。

### 3.3 两次一维线性插值合成二维插值
双线性插值本质是先后沿两个轴向执行一维 Lerp：
1. **第一步（Y 方向插值）**：
   在左列上对上下两点插值得到 $R_1$，在右列上对上下两点插值得到 $R_2$：
   $$R_1 = \text{lerp}(Q_{11}, Q_{12}, y_{\text{scale}}) = (1 - y_{\text{scale}}) Q_{11} + y_{\text{scale}} Q_{12}$$
   $$R_2 = \text{lerp}(Q_{21}, Q_{22}, y_{\text{scale}}) = (1 - y_{\text{scale}}) Q_{21} + y_{\text{scale}} Q_{22}$$
2. **第二步（X 方向插值）**：
   在 $R_1$ 和 $R_2$ 之间沿 X 方向做最终插值：
   $$P = \text{lerp}(R_1, R_2, x_{\text{scale}}) = (1 - x_{\text{scale}}) R_1 + x_{\text{scale}} R_2$$

展开得到四个顶点的四次联合权重多项式：
$$P = (1 - x_{\text{scale}})(1 - y_{\text{scale}}) Q_{11} + x_{\text{scale}}(1 - y_{\text{scale}}) Q_{21} + (1 - x_{\text{scale}}) y_{\text{scale}} Q_{12} + x_{\text{scale}} y_{\text{scale}} Q_{22}$$
四个权重之和严格恒等于 1，满足色彩守恒。通过加权平均，消除了像素间的跳变阶梯，产生了高质量的平滑纹理过渡。

## 4. 性能优化与高阶滤波算法扩展

### 4.1 定点数移位优化（Fixed-Point Optimization）
对于 8 位 RGBA 贴图，浮点乘法开销较大。可将 $[0.0, 1.0]$ 的浮点权重放大 256 倍（$2^8$），使用 8 位小数的定点数进行整型插值，最后右移 8 位：
```cpp
uint8_t fastBilinear(uint8_t q11, uint8_t q12, uint8_t q21, uint8_t q22, int fx, int fy) {
    // fx, fy 为 [0, 256] 区间的定点数权重
    int r1 = ((256 - fx) * q11 + fx * q21) >> 8;
    int r2 = ((256 - fx) * q12 + fx * q22) >> 8;
    return static_cast<uint8_t>(((256 - fy) * r1 + fy * r2) >> 8);
}
```
完全避免了浮点运算指令，在早期的嵌入式软光栅与移动端软渲染引擎中极为常用。

### 4.2 双三次插值（Bicubic Filtering）
双线性插值仅使用一阶多项式，虽然连续但一阶导数不连续，在极端放大时能看到网格方向的折线斜痕。
- **双三次插值**：考虑周围 $4 \times 4 = 16$ 个临近纹素，采用三次多项式（如 Catmull-Rom 样条）加权。
- **视觉效果**：能够保留更清晰的物体高频轮廓和边缘锐度，但计算开销增加约 4 倍。

### 4.3 Lanczos 重采样
使用 Sinc 函数窗口化核函数作为插值基底：
$$L(x) = \begin{cases} \text{sinc}(x) \cdot \text{sinc}(x / a), & -a < x < a \\ 0, & \text{otherwise} \end{cases}$$
在频域上最逼近理想低通滤波器，广泛应用于影视后期与高保真图像缩放，但计算量过大，极少在实时管线中直接使用。
